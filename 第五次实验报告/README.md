# 第五次实验报告使用说明

## blinky/
仅用于**打开 I2C**，同时运行软件定时器（`timer.c`）。  
`timer.c` 基于 `uapi_timer` 实现每秒触发一次的回调，在串口输出 `时:分:秒` 计时，计时从 `00:00:00` 开始。

**和 `timer_demo.c` 的区别**：`timer.c` 是自己修改过的带时间显示的版本；`timer_demo.c` 是 SDK 原版示例，用于分析（见下）。

## INS5699/
使用 RTC 芯片 **INS5699S**（I2C 地址 `0x64`）输出时间。

- 可在 `main.c` 的 `initial_time` 结构体中修改初始时间（年用后两位，如 2025 年填 `25`）。
- 星期范围 1~7（1 = 周一），月份范围 1~12，日期范围视月份而定（代码中仅对 4 月做了天数检验）。
- 芯片寄存器使用 **BCD 码**存储时间，驱动内已自动转换，使用者直接填十进制数字即可。
- 串口输出示例：`现在是2025年 4月21日,星期1,08:00:05`

## timer_demo.c
SDK 原版 4 路定时器示例，**作业要求是分析代码和运行结果，不需要修改**。  
4 个定时器分别设为 1ms / 2ms / 3ms / 4ms 延时，到期后打印实测时间与设定时间的误差。
