## 如何使用这份代码

这里的源文件**不能单独编译**，需要放入 HiSilicon SDK 的工程目录中：

1. 在 SDK 中找到 `application/samples/blinky/`（或对应的 app 目录）。
2. 将本实验对应文件夹中的 `.c` / `.h` 文件复制进去。
3. 修改该目录下的 `CMakeLists.txt`，将新文件加入 `SOURCES`（参考各实验文件夹内的 `CMakeLists.txt`）。
4. 用 SDK 提供的构建脚本正常编译烧录。

## 各实验说明

### 第四次实验报告
通过 I2C 同时驱动两个传感器：
- **BH1750FVI**：光照传感器，I2C 地址 `0x46`，连续高分辨率模式，返回 lux 值。
- **CW2015**：电池电量计，I2C 地址 `0xC4`，读取电芯电压（单位 mV）。

### 第五次实验报告
包含三个相对独立的部分：
- **blinky/**：仅用于打开 I2C，并运行软件定时器（`timer.c`），每秒回调一次，在串口打印计时。
- **INS5699/**：通过 I2C 操作 INS5699S RTC 芯片，可设置初始时间后软件自增输出。时间格式为 BCD 码，代码内已处理转换。
- **timer_demo.c**：SDK 原版 4 路定时器示例，作业要求分析代码和运行结果，不需要修改。

### 第六次实验报告
通过 I2C 向地址 `0x5A` 的电机驱动 IC 发送 3 字节 PWM 控制包：
- `left_wheel_set(CRR, limit, dir)`：左轮，`dir=true` 前进
- `right_wheel_set(CRR, limit, dir)`：右轮，`dir=true` 前进
- CRR 范围建议 0~1000，limit 用于限速保护
