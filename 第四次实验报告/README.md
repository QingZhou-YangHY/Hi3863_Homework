# 第四次实验报告使用说明

## 实验内容
通过 I2C 同时读取两个传感器的数据，每 5 秒在串口输出一次。

## 文件说明

| 文件 | 说明 |
|------|------|
| `BH1750FVI.h / .c` | 光照传感器驱动，I2C 地址 `0x46` |
| `CW2015.h / .c` | 电量计驱动，I2C 地址 `0xC4` |
| `main.c` | 主程序，初始化 I2C 后循环读取并打印 |

## 使用步骤

1. 将本文件夹下所有 `.c` / `.h` 文件复制到 SDK blinky app 目录。
2. 在 `CMakeLists.txt` 的 `SOURCES` 中添加 `BH1750FVI.c`、`CW2015.c`、`main.c`。
3. 编译烧录后，串口输出示例：
   ```
   BH1750:00312
   CW2015:03750
   ```
   BH1750 单位为 lux，CW2015 单位为 mV。

## 注意事项

- `BH1750FVI.h` 中 `#define BH1750_RES 1` 对应高分辨率模式（1 lux 精度），如需改成高分辨率模式 2（0.5 lux）请同时修改 `MEASURE_MODE` 和分辨率系数。
- CW2015 电压计算公式：`(高字节<<8 | 低字节) * 305 / 1000`，单位 mV。
